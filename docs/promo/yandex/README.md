# Медиафайлы для Яндекс Игр

Основные материалы для карточки игры уже подготовлены.

## Основной набор
- квадратная иконка для карточки;
- иконка для адаптивной маски;
- широкая обложка для карточки;
- три основных снимка для компьютера;
- два основных снимка для телефона.

## Видео
- видео игрового процесса в горизонтальном формате;
- видео игрового процесса в вертикальном формате;
- анимированное изображение для дополнительного медиа-поля;
- рекламное видео в горизонтальном формате;
- рекламное видео в вертикальном формате.

## Запасные варианты
- дополнительная иконка для витрины;
- дополнительная обложка для витрины;
- дополнительный снимок экрана с результатами.

## Как использовать
- для загрузки в консоль берите основной набор;
- если витрина выглядит слабее ожидаемого, замените иконку или обложку запасным вариантом;
- снимки экрана должны совпадать с текущим интерфейсом и реальным игровым процессом.

## Повторная подготовка
- локальный сценарий заново снимет игровые экраны;
- затем обновит иконку и обложку в нужных размерах;
- после этого можно пересобрать пакет для публикации.
