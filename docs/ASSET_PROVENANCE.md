# Подтверждение Прав На Материалы

Этот документ описывает происхождение материалов, которые входят в `Magnet Caravan` и в пакет для Яндекс Игр.

## Что Используется В Игре
- Графика геймплея в `public/assets/generated/` создаётся локально внутри проекта скриптом `scripts/generate_visual_assets.mjs` и рантайм-фабриками текстур из `src/visual/`.
- Звуки и музыка в `public/assets/audio/` создаются локально внутри проекта скриптом `scripts/generate_audio_assets.mjs`.
- Игровые тексты, описания и локализация хранятся в исходниках проекта и написаны специально для `Magnet Caravan`.
- Медиа для карточки в `docs/promo/yandex/` подготовлены из актуального геймплея и интерфейса этой игры.

## Что Не Используется
- В финальной сборке нет логотипов, маскотов, интерфейсных элементов или брендовых материалов Яндекса.
- В игровых текстах и в подготовленных полях карточки нет ссылок на чужие бренды как на часть контента игры.
- В пакет публикации не включаются стоковые изображения, сторонние музыкальные библиотеки и внешние брендовые наборы.

## Исходники Для Проверки
- Генерация графики: `scripts/generate_visual_assets.mjs`
- Генерация аудио: `scripts/generate_audio_assets.mjs`
- Игровые ассеты: `public/assets/`
- Тексты карточки: `docs/platform_texts/yandex_ru.md`, `docs/platform_texts/yandex_en.md`
- Медиа карточки: `docs/promo/yandex/`

## Заявление Разработчика
Все материалы, входящие в текущую публикационную сборку `Magnet Caravan`, подготовлены разработчиком проекта или сгенерированы локально средствами этого репозитория для использования в данной игре.
