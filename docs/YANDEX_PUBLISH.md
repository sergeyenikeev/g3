# Публикация в Яндекс Игры

Этот документ нужен как практическая памятка по выпуску `Magnet Caravan` в Яндекс Игры.

## На что опираться
- быстрый старт по платформе;
- требования к игре и карточке;
- описание платформенного набора;
- добавление новой игры в консоли;
- правила монетизации.

## Что уже готово в игре
- платформенный набор подключается по штатной схеме для архивной публикации;
- загрузочный экран корректно завершается после готовности игры;
- игровые паузы и возобновления обрабатываются через платформенные события;
- игровые данные сохраняются в облаке через платформу;
- язык определяется по подсказке платформы и не откатывается на старте;
- ежедневный режим опирается на серверное время, а не на локальные часы;
- реклама за награду и полноэкранная реклама идут только через платформенные вызовы;
- музыка запускается только после действия пользователя.

## Что загружать в консоль
- отдельный архив игры из подготовленного пакета;
- основную иконку для карточки;
- основную обложку для карточки;
- три основных снимка для компьютера;
- два основных снимка для телефона;
- тексты карточки из папки с подготовленными материалами;
- комментарий разработчика на втором языке.

## Русские тексты для карточки

### Короткое описание
Собирайте металлолом магнитом, выстраивайте хвост-караван и сдавайте его в переработчик. Импульс помогает оттолкнуть врагов и отразить снаряды.

### Полное описание
`Magnet Caravan` — аркадная игра с видом сверху для горизонтального экрана. Управляйте тягачом виртуальным джойстиком или клавишами движения, собирайте металлолом, удлиняйте караван и в нужный момент сдавайте добычу в зону переработки, получая болты и восстановление прочности.

Враги приходят волнами, а сложность нарастает постепенно: игра следит за безопасной дистанцией появления, предупреждает о новых угрозах и меняет состав роя по ходу забега. Между волнами вы выбираете улучшения и собираете свой стиль игры.

Есть ежедневный режим с особым набором правил и модификаторов дня.

### Как играть
Ведите тягач джойстиком, клавишами движения или стрелками. Собирайте металлолом, чтобы увеличить караван. Нажимайте импульс, чтобы отталкивать врагов и отражать снаряды. Заезжайте в зону переработки и оставайтесь в ней, пока добыча не будет сдана. После каждой волны выбирайте улучшение и подстраивайте сборку под текущий забег.

## Монетизация
- реклама за награду: возрождение, удвоение награды на экране итогов, повторный выбор улучшения, дополнительная попытка ежедневного режима, стартовый бонус;
- полноэкранная реклама: только на экране итогов и вне активного игрового процесса;
- реклама не должна появляться в середине боя, до завершения обучения и сразу после рекламы за награду.

## Креативы и медиафайлы
- квадратная иконка для карточки;
- широкая обложка для карточки;
- три горизонтальных снимка для компьютера;
- два горизонтальных снимка для телефона;
- на снимках должен быть только реальный игровой процесс и актуальный интерфейс;
- если на изображении есть текст, он должен совпадать с языком набора.

## Что проверить перед отправкой
- загрузочный экран и меню открываются без ошибок;
- поле «Как играть» на русском берётся только из русского файла;
- кнопки с рекламой за награду прямо сообщают о просмотре рекламы;
- на узких и широких размерах окна интерфейс не наезжает сам на себя;
- правый клик и выделение текста внутри игры не срабатывают;
- в игре нет стартовых и игровых ошибок.
