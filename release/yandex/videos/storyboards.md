# Сценарии видеороликов для Яндекс Игр

Все четыре ролика собраны из реального игрового процесса Magnet Caravan (без фейковой механики, без debug-оверлеев и водяных знаков). Каждый ролик — отдельный файл MP4 / H.264 в этой папке.

## A. Gameplay horizontal — 16:9, до 28 сек

Файл: `gameplay-horizontal-16x9.mp4` (1920×1080, ~18 сек).

| Тайминг | Что показано | Цель |
|---------|--------------|------|
| 0–2 сек | Тягач едет по арене, магнит уже подтягивает первые куски лома. | Игрок мгновенно видит USP — притяжение и хвост. |
| 2–8 сек | Караван-хвост вытягивается, в кадр входит враг-преследователь. | Базовая механика магнита и роста хвоста. |
| 8–14 сек | Импульс полярности оттталкивает врагов и отбивает снаряд; короткая пауза неуязвимости. | Демонстрация Flip как «вау-кнопки». |
| 14–18 сек | Тягач въезжает в зону переработчика, хвост сдаётся, на HUD растут болты. | Закрытие цикла «собрал → сдал → получил награду». |

Гейплей занимает 100 % длительности (≥ 70 % требование выполнено).

## B. Gameplay vertical — 9:16, до 28 сек

Файл: `gameplay-vertical-9x16.mp4` (1080×1920, ~18 сек).

Композиция:
- Игровое поле занимает центральную полосу 1080×1080.
- Сверху и снизу — лёгкое затемнение поля, чтобы не растягивать горизонтальную картинку.
- HUD (HP, импульс, волна, болты) и зона переработчика всегда в кадре.

| Тайминг | Что показано |
|---------|--------------|
| 0–2 сек | Магнит притягивает лом, формируется первый сегмент хвоста. |
| 2–10 сек | Враги налетают, игрок маневрирует, хвост растёт. |
| 10–14 сек | Flip + дефлект снарядов. |
| 14–18 сек | Сдача каравана в переработчике, бодрая анимация награды. |

Все важные элементы UI остаются в безопасной зоне 9:16, ничего не обрезано.

## Общие требования (все ролики)

- Источник — реальный геймплей из локальной сборки Magnet Caravan (платформенный мок-адаптер, `VITE_PLATFORM_ADAPTER=mock`, `VITE_E2E=1`).
- Используется штатная игровая графика и официальные UI-тексты (RU/EN — по локализации игры).
- Нет debug-оверлеев, FPS-счётчиков, console errors, окон ОС/браузера.
- Нет фоновой музыки из внешних источников с непонятными правами. Аудиодорожка либо тихая (~0 dBFS), либо взята из штатных game-effects.
- Нет мелкого нечитаемого текста и обрезанного UI.
- Длительность всех роликов ≤ 28 сек, размер каждого файла ≤ 12 MB (запас по 100 MB лимиту платформы).
