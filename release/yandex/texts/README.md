# Тексты для черновика Яндекс Игр

В этой папке лежат итоговые тексты для карточки игры на двух языках.

## Файлы

- `yandex-draft-ru.md` — русские тексты в человеко-читаемом виде с комментариями по длинам.
- `yandex-draft-en.md` — английские тексты с теми же полями.
- `yandex-draft-ru.json` — машино-читаемый формат для копипасты в консоль (RU).
- `yandex-draft-en.json` — машино-читаемый формат (EN).

## Поля карточки

Каждый файл закрывает один и тот же набор полей черновика:

| Поле | RU | EN |
|------|----|----|
| Название | 14 симв. | 14 симв. |
| Короткое описание | 64 симв. | 68 симв. |
| SEO-описание | 117 симв. | 123 симв. |
| Полное описание | 802 симв. | 758 симв. |
| Как играть | 793 симв. | 723 симв. |
| Версия | 1.0.0 | 1.0.0 |
| Платформы | Компьютер, Телефон | Desktop, Mobile |
| Ориентация | Горизонтальная | Landscape |
| Возрастной рейтинг | 12+ | 12+ |
| Категории | Аркады, Экшен | Arcade, Action |
| Теги | 20 | 20 |
| Ключевые слова | 86 симв. | 78 симв. |
| Облачные сохранения | Включены | Enabled |

## Версия

В `package.json` указано `0.1.0` (внутренняя разработка). В черновик карточки публикуем `1.0.0` — это уведомительная цифра только для модерации/витрины.

## Облачные сохранения

Подтверждено по коду: `src/platform/adapters/yandexGamesPlatformAdapter.ts` вызывает `player.getData()` и `player.setData(data, true)`. Можно смело включать чекбокс «Облачные сохранения».

## Куда вставлять

- В консоли Яндекс Игр откройте черновик игры → раздел «Локализация».
- Для языка «Русский» вставьте данные из `yandex-draft-ru.json` / `.md`.
- Для языка «Английский» вставьте данные из `yandex-draft-en.json` / `.md`.
- Поля «Категории», «Теги», «Ключевые слова», «Возрастной рейтинг», «Ориентация», «Платформы» заполняйте одинаково для обоих языков.
