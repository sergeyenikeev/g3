# Аудит проекта для публикации в Яндекс Играх

Дата: 2026-05-27.
Игра: Magnet Caravan.
Версия package.json: 0.1.0.

## Стек и точка входа

- Стек: HTML5 / TypeScript / Vite 6 / Phaser 3.88.
- Точка входа браузера: `index.html` → `/src/main.ts`.
- Сборка релиза: `npm run build:yandex` (через `scripts/build_platform_release.mjs yandex`).
- Локальный запуск:
  - dev-сервер: `npm run dev` (Vite, host 127.0.0.1, порт 4173/строгий);
  - preview сборки: `npm run preview`.
- Платформенный адаптер для Яндекса: `src/platform/adapters/yandexGamesPlatformAdapter.ts` (LoadingAPI.ready, GameplayAPI.start/stop, fullscreen+rewarded ads, player.getData/setData, leaderboards, environment.i18n.lang, serverTime).

## Локализация и языки

- Файл локализации: `src/i18n/localization.ts` (Locale = "en" | "ru").
- Карточные тексты были подготовлены частично:
  - `docs/platform_texts/yandex_ru.md` — корректный русский текст;
  - `docs/platform_texts/yandex_en.md` — НЕ английский: содержит русский текст (баг карточки). Зафиксировано как материал карточки, новые драфты `release/yandex/texts/yandex-draft-en.md` полностью переведены на английский.
- Кодировка платформенных RU-документов: UTF-8 (рекомендуется BOM — есть авто-проверка `npm run bom-check`).

## Существующие медиа-материалы

- `docs/promo/yandex/card/` — иконка 512x512, иконка-альтернатива 512x512, обложка 800x470, обложка-альтернатива 800x470, маскируемая иконка 512x512.
- `docs/promo/yandex/desktop/` — 4 скриншота 1600x900 (меню, геймплей, выбор апгрейда, итоги).
- `docs/promo/yandex/mobile/` — 2 скриншота 1280x720 (геймплей, итоги).
- `docs/promo/yandex/video/` — 4 MP4 (gameplay 16:9, gameplay 9:16, ad 16:9, ad 9:16), 1 GIF 800x450, manifest.json.

Все материалы соответствуют требованиям платформы (см. отчёт `release/yandex/checklists/image-check-report.md` и `release/yandex/videos/video-check-report.md`). Для публикационного пакета перенесены в `release/yandex/` под унифицированными именами по ТЗ.

## Возможность локального запуска

- Локальный запуск возможен: проект Vite, dev-сервер запускается командой `npm run dev`.
- Headless-захват уже автоматизирован: `npm run media:yandex` / `npm run media:yandex:promo` поднимают Vite с `VITE_PLATFORM_ADAPTER=mock` и `VITE_E2E=1`, делают скриншоты и видео через Playwright + ffmpeg-static.
- При повторной генерации можно использовать существующие пайплайны, либо новые скрипты в `release/yandex/tools/` (см. этот аудит).

## Проверка консоли / артефактов сборки

Поскольку код игры менять запрещено, фактическая консоль не открывалась. Косвенные индикаторы из репозитория:

- Логи `tmp-codex-dev.out.log`, `dev4176.log` показывают штатные старты dev-сервера без runtime-ошибок.
- В `artifacts/yandex-publish-pass/` уже зафиксированы прогоны проверки публикации (`npm run audit:yandex`).
- В `artifacts/ui-audit/matrix/` лежит матрица UI-скриншотов под разные разрешения; debug-overlay в финальных кадрах не виден.
- В коде SDK-адаптер вызывает `LoadingAPI.ready` после готовности и `GameplayAPI.start/stop` на старте/остановке боя, что соответствует требованиям Яндекс Игр.

## Что нельзя исправить без отдельного разрешения (раздел "Требуется отдельное разрешение")

1. Замена/перекодировка `docs/platform_texts/yandex_en.md` на действительно английский текст внутри самого репозитория проекта.
2. Перекодировка строк в `scripts/assemble_yandex_upload.mjs` под чистый UTF-8 без артефактов.
3. Любые правки рантайма / ассетов / `package.json["dependencies"]`.

Все эти пункты при необходимости можно сделать отдельным маленьким PR — параметры и тексты к нему уже подготовлены в `release/yandex/texts/`.
